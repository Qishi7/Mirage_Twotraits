Objective

This page summarizes a preliminary real-data exploration of the two-trait MIRAGE extension using autism as trait 1 and schizophrenia as trait 2.

The goal is not to present a finalized association analysis. Instead, the goal is to test whether the two public summary VCFs can be converted into a common variant-level input matrix, whether joint MIRAGE can run on the resulting data, and whether the top-ranked genes agree with external knowledge.

Data Sources

Trait 1 uses the Autism Sequencing Consortium (ASC) summary VCF. Trait 2 uses the SCHEMA schizophrenia summary VCF.

The analysis uses summary allele counts only:

Trait Case count field Control count field Notes
ASC autism ac_case ac_ctrl Array-valued fields were summed over entries with in_analysis=1.
SCHEMA schizophrenia ac_case ac_ctrl Only variants with in_analysis=1 were used.

De novo counts were not used. For SCHEMA, the n_de_novo field was ignored.

Variant Groups

Both traits were mapped to the same six annotation groups used in the original MIRAGE ASD analysis:

Group Definition
LoF, low LOEUF Loss-of-function variant in a gene with LOEUF decile 1
LoF, medium LOEUF Loss-of-function variant in a gene with LOEUF decile 2-3
LoF, high LOEUF Loss-of-function variant in a gene with LOEUF decile 4-10
Missense, high MPC Missense variant with MPC >= 2
Missense, medium MPC Missense variant with 1 <= MPC < 2
Missense, low MPC Missense variant with MPC < 1

LOEUF deciles were assigned from the gnomAD v2.1.1 gene constraint table. The ASC and SCHEMA VCFs contain consequence and mpc, but not a direct gnomAD allele-frequency field. The working rare-variant filter therefore used the within-cohort pooled allele frequency, AF <= 0.1%.

Variant Overlap

The correct joint input uses the union of variant indices, not only shared variants. A variant index is defined as:

chromosome + position + reference allele + alternate allele

If a variant appears only in ASC, its SCHEMA case/control counts are set to zero. If a variant appears only in SCHEMA, its ASC case/control counts are set to zero.

Using only the exact variant intersection would discard nearly all rare variants.

Separate MIRAGE Diagnostic

To determine whether the broad SCHEMA signal came from the joint layer or from the single-trait SCHEMA likelihood, separate MIRAGE fits were run for each trait.

Trait Estimated risk-gene proportion Genes with PP > 0.8
ASC autism 0.225 16
SCHEMA schizophrenia 0.639 3,375

This shows that the broad SCHEMA signal is already present in the separate single-trait analysis. It is not created mainly by the joint shared state.

The likely explanation is calibration: SCHEMA has many more observed variants and much larger allele numbers than ASC, and the six broad annotation groups allow background burden to be interpreted as widespread risk-gene signal.

Joint Fits

Two fixed-prior strategies were compared.

The first strategy fixed the full four-state prior:

pi00 = 0.94
pi10 = 0.02
pi01 = 0.03
pi11 = 0.01

This prior is sparse at the gene-state level. It means that most genes are assumed a priori to be null, with smaller prior mass assigned to autism-only, schizophrenia-only, and shared-risk states.

The second strategy fixed only the marginal schizophrenia risk-gene proportion:

pi01 + pi11 = 0.05

Under this partial constraint, the autism-only proportion, the split between schizophrenia-only and shared risk, and the null proportion were still estimated from the data.

Burden Test

As a simple baseline, gene-level case-control burden tests were run separately for ASC and SCHEMA. For each gene, allele counts and allele numbers were summed across the six MIRAGE annotation groups, and a two-sided Fisher exact test was used to test:

H0: case allele frequency = control allele frequency

This baseline produces only single-trait results. It can identify ASC burden genes and SCHEMA burden genes, but it does not estimate shared or pleiotropic gene states.

Baseline Trait Genes tested Case-enriched p < 0.05 Case-enriched p < 0.01 Case-enriched BH FDR < 5%
All six groups combined ASC autism 17,581 105 13 0
All six groups combined SCHEMA schizophrenia 18,009 2,094 899 250

The six-group joint MIRAGE fit with SCZ marginal risk fixed at 5% selected 18 autism genes and 297 SCHEMA genes at Bayesian FDR < 5%. These were compared with the corresponding single-trait burden baselines:

The overlap pattern is asymmetric. SCHEMA MIRAGE results are highly concordant with ordinary case-control burden evidence, whereas ASC burden testing alone is much weaker. This suggests that MIRAGE adds the most beyond a simple burden test for autism gene prioritization, while SCHEMA is already strongly driven by single-trait burden enrichment.

For completeness, the three LoF groups were also combined into a separate single-trait burden baseline:

Baseline Trait Genes tested Case-enriched p < 0.05 Case-enriched p < 0.01 Case-enriched BH FDR < 5%
Three LoF groups combined ASC autism 11,465 116 14 0
Three LoF groups combined SCHEMA schizophrenia 17,553 1,921 716 137

These LoF-only burden tests support the same conclusion: the SCHEMA case-control burden signal is strong, while the ASC burden signal is not strong enough to survive gene-level multiple testing.

Interpretation

This exploration supports three practical conclusions.

First, ASC and SCHEMA should be joined by the union of variant indices rather than by the exact variant intersection. Exact rare-variant overlap is almost zero, but gene-level overlap is high.

Second, the autism signal is robust and biologically credible. The top autism genes are highly enriched for SFARI score-1 genes.

Third, SCHEMA requires calibration. With freely estimated gene-risk proportions, the model assigns high posterior probability to too many schizophrenia genes. Fixing the SCZ marginal risk-gene proportion at 5% gives a more interpretable joint result while retaining known schizophrenia genes near the top.

Current Recommendation

The most useful real-data analysis setting for continued development is:

Trait 1: ASC autism
Trait 2: SCHEMA schizophrenia
Variant input: union variant index
Variant groups: all six MIRAGE annotation groups
Gene-state prior: fix SCZ marginal risk at 5%, estimate the remaining pi values

This should be treated as a preliminary calibrated real-data exploration, not as a finalized discovery analysis.
