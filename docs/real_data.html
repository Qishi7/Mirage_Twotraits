    Real Data Exploration

    Objective

    This page summarizes a preliminary real-data exploration of the two-trait MIRAGE extension using autism as trait 1 and schizophrenia as trait 2.

    The goal is not to present a finalized association analysis. Instead, the goal is to test whether the two public summary VCFs can be converted into a common variant-level input matrix, whether joint MIRAGE can run on the resulting data, and whether the top-ranked genes agree with external knowledge.

    Data Sources

    Trait 1 uses the Autism Sequencing Consortium (ASC) summary VCF. Trait 2 uses the SCHEMA schizophrenia summary VCF.

    The analysis uses summary allele counts only:

    TraitCase count fieldControl count fieldNotes
    ASC autismac_caseac_ctrlArray-valued fields were summed over entries with in_analysis=1.
    SCHEMA schizophreniaac_caseac_ctrlOnly variants with in_analysis=1 were used.

    De novo counts were not used. For SCHEMA, the n_de_novo field was ignored.

    Variant Groups

    Both traits were mapped to the same six annotation groups used in the original MIRAGE ASD analysis:

    GroupDefinition
    LoF, low LOEUFLoss-of-function variant in a gene with LOEUF decile 1
    LoF, medium LOEUFLoss-of-function variant in a gene with LOEUF decile 2-3
    LoF, high LOEUFLoss-of-function variant in a gene with LOEUF decile 4-10
    Missense, high MPCMissense variant with MPC >= 2
    Missense, medium MPCMissense variant with 1 <= MPC < 2
    Missense, low MPCMissense variant with MPC < 1

    LOEUF deciles were assigned from the gnomAD v2.1.1 gene constraint table. The ASC and SCHEMA VCFs contain consequence and mpc, but not a direct gnomAD allele-frequency field. The working rare-variant filter therefore used the within-cohort pooled allele frequency, AF <= 0.1%.

    Variant Overlap

    The correct joint input uses the union of variant indices, not only shared variants. A variant index is defined as:

    chromosome + position + reference allele + alternate allele

    If a variant appears only in ASC, its SCHEMA case/control counts are set to zero. If a variant appears only in SCHEMA, its ASC case/control counts are set to zero.

    Using only the exact variant intersection would discard nearly all rare variants.

    Separate MIRAGE Diagnostic

    To determine whether the broad SCHEMA signal came from the joint layer or from the single-trait SCHEMA likelihood, separate MIRAGE fits were run for each trait.

    TraitEstimated risk-gene proportionGenes with PP > 0.8
    ASC autism0.22516
    SCHEMA schizophrenia0.6393,375

    This shows that the broad SCHEMA signal is already present in the separate single-trait analysis. It is not created mainly by the joint shared state.

    The likely explanation is calibration: SCHEMA has many more observed variants and much larger allele numbers than ASC, and the six broad annotation groups allow background burden to be interpreted as widespread risk-gene signal.

    Calibration Exploration

    Two simple calibration strategies were explored. First, the SCHEMA single-trait risk-gene proportion was fixed to sparse values instead of being freely estimated. Second, the variant set was restricted to the three strongest annotation groups:

    LoF, LOEUF decile 1
LoF, LOEUF decile 2-3
Missense, MPC >= 2

    Joint Fits

    The sparse fixed prior used:

    pi00 = 0.94
pi10 = 0.02
pi01 = 0.03
pi11 = 0.01

    This prior is sparse at the gene-state level. It means that most genes are assumed a priori to be null, with smaller prior mass assigned to autism-only, schizophrenia-only, and shared-risk states.

    External Validation

    Autism genes were compared with the SFARI gene-scoring database. SFARI score 1 genes were treated as high-confidence autism-risk genes for this exploratory check.

    Schizophrenia genes were compared with published SCHEMA exome-significant genes:

    SETD1A, CUL1, XPO7, TRIO, CACNA1G, SP4, GRIA3, GRIN2A,
HERC1, RB1CC1, STAG1, ZNF136

    The first ten genes come from the SCHEMA exome-sequencing study; STAG1 and ZNF136 were added from the later SCHEMA expansion.

    Interpretation

    This exploration supports three practical conclusions.

    First, ASC and SCHEMA should be joined by the union of variant indices rather than by the exact variant intersection. Exact rare-variant overlap is almost zero, but gene-level overlap is high.

    Second, the autism signal is robust and biologically credible. The top autism genes are highly enriched for SFARI score-1 genes.

    Third, SCHEMA requires calibration. With freely estimated gene-risk proportions, the model assigns high posterior probability to too many schizophrenia genes. Using a stricter damaging-variant set and a sparse gene-state prior gives a more interpretable result while retaining known schizophrenia genes near the top.

    Current Recommendation

    The most useful real-data analysis setting for continued development is:

    Trait 1: ASC autism
Trait 2: SCHEMA schizophrenia
Variant input: union variant index
Variant groups: strict three groups
Gene-state prior: sparse fixed pi

    This should be treated as a preliminary calibrated real-data exploration, not as a finalized discovery analysis.
